# 3D Coconut Runner

**Tech Stack**: Three.js (r128), HTML5 Canvas, WebGL, Modern JavaScript (ES6+)  
**Commercial Partner**: Jonat Coco Lanka (Pvt) Ltd  

## Game Features
- **Deterministic Object Pooling**: Re-uses 3D obstacle meshes and track tiles to prevent garbage-collection latency spikes on lower-end mobile devices.
- **Custom Bounding-Volume Physics**: AABB (Axis-Aligned Bounding Box) collision detection with lane-switch interpolation.
- **Dynamic Speed Progression**: Quadratic acceleration curve increasing game difficulty based on distance traveled.
- **Corporate Branding**: Integrates coconut plantation environmental themes and brand logos into in-game pickups.
