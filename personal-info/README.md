```
personal-info/
├── README.md                   # This documentation file
├── data.js                     # Scrabble board crossword configuration & dossier contents
├── cv/                         # Full Curriculum Vitae & resumes
│   └── resume.md
├── bio/                        # Detailed biography & personal narrative
│   └── biography.md
├── education/                  # Academic credentials & Faculty of Science stream
│   └── university-of-colombo.md
```

## How to Update Personal Details

1. Update your resumes, biography notes, or venture details in the respective subfolders.
2. Open `data.js` in this folder to modify the text displayed in the decrypted reading pane when visitors solve the Scrabble crossword!
