# Enterprise Complaint Management System

**Tech Stack**: PHP 8.x, MySQL, HTML5, CSS3, JavaScript  
**Context**: Second-year University Academic Web Systems Deployment  

## System Highlights
- **Multi-Role RBAC**: Distinct interfaces and permission sets for Students, Departmental Staff, and Chief Administrators.
- **Dynamic Ticket Lifecycles**: Open $\rightarrow$ In Review $\rightarrow$ Escalated $\rightarrow$ Resolved with audit logging.
- **SQL Sanitization**: Prepared statements with PDO ensuring defense against SQL injection and XSS vectors.
- **Responsive Dashboard**: Custom CSS grid interface optimized for desktop and mobile viewports.
