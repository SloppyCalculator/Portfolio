# Digital Game Design
## Board Game & Simulation Development

**Badge**: GAME DEV
**Tagline**: Translating physical mechanics into deep digital strategy.

### Summary
Johan Sofalas brings physical board game mechanics to life through digital development, utilizing Python and Tkinter to build interactive card games, board games, and management simulators. Driven by a passion for algorithmic structure, his focus remains entirely on the backend logic and gameplay loops—prioritizing emergent strategic depth and solid mechanics over complex controls or flashy graphics.

### Specs
- STACK: Python, Tkinter, JS
- CORE FOCUS: Algorithms & Logic
- GENRE: Board Games & Simulators
- STYLE: Strategic Depth

### Highlights
- Translates physical board game economies and mechanics into digital formats.
- Prioritizes strategic gameplay depth over complex UI controls.
- Treats digital game design as an exercise in structural problem-solving.
